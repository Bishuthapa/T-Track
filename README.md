# T-Track

Personal money tracker. Accounts and wallets (cash, bank, eSewa, Khalti, cards), income and expenses, transfers, budgets, recurring bills, money lent and borrowed, savings goals, and reports — with AD/BS dates and NPR first.

**Stack:** .NET 10 Web API · EF Core + Dapper · SQL Server · Vue 3 + Vite + PrimeVue 4 + Pinia · Hangfire · Serilog · xunit / Vitest / Playwright · Capacitor (mobile).
